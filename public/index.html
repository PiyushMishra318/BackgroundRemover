Grayscale threshold → alpha channel → transparent PNG · same algorithm as bg-cutout-py

Why Threshold

  • ◐ One knob, clear mask Pick a threshold 0–255; pixels above or below become your alpha — invert when the backdrop is dark.
  • ⬡ Windows build ready Grab bg-cutout-windows-x64.exe from Releases — no local OpenCV install required.
  • ⇄ Same pipeline, two CLIs Fast C++ binary or portable bg-cutout-py — identical BGRA PNG output.

How it works

Load, grayscale, threshold

OpenCV reads your image, converts to grayscale, and applies a binary threshold to build the alpha mask.

1 BGR image 2 Grayscale + threshold 3 Alpha mask

Export BGRA with transparency

Blue, green, red, and alpha merge into a PNG you can drop into slides, thumbnails, or compositing workflows.

bg-cutout input.jpg out.png -t 240 bg-cutout-py -i photo.jpg -o cut.png --invert

Usage

bg-cutout-windows-x64.exe input.jpg output.png --threshold 240
bg-cutout-py input.jpg output.png --threshold 240

Build C++ with CMake, or pip install -e . for the Python entry point. See the repo README for flags like --invert and --preview.
